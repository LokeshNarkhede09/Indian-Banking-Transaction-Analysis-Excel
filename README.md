# Indian Banking Transaction Analysis using Excel

## 📌 Project Overview

This project focuses on analyzing Indian banking transaction data using Microsoft Excel.

The project includes data cleaning, data analysis, Pivot Tables, and an interactive dashboard to understand transaction amounts, regions, branches, transaction types, payment methods, and transaction statuses.

## 🎯 Project Objective

The main objective of this project is to analyze banking transaction data and identify useful business insights from different aspects of the transactions.

The analysis helps understand:

- Transaction performance across different regions
- Transaction amounts by branch
- Different types of transactions
- Monthly transaction trends
- Transaction status
- Payment methods used by customers

## 📊 Dataset

The dataset contains Indian banking transaction information.

The cleaned dataset contains **500 transactions** and includes fields such as:

- Transaction ID

- City

## 🔄 Project Workflow

The project was completed in the following steps:

### 1. Raw Data

The original banking transaction data was collected and reviewed.

### 2. Data Cleaning

The raw data was cleaned and prepared for analysis.

The cleaned data includes additional date-related fields such as:

- Year
- Month
- Day
- Year-Month

These fields helped in performing time-based analysis.

### 3. Pivot Table Analysis

Pivot Tables were created to analyze:

- Transaction amount by region
- Transaction amount by month
- Transaction amount by branch
- Transaction amount by transaction type
- Transaction status
- Payment method

### 4. Dashboard

The analyzed data was presented through an Excel dashboard to make the results easier to understand.

The dashboard provides a visual view of important banking transaction information.

## 📈 Key Analysis

### Transaction by Region

The total transaction amount was analyzed across different regions:

- North
- South
- East
- West
- Central

The **North region recorded the highest transaction amount** among the regions in the analysis.

### Transaction by Type

The project analyzed four major transaction types:

- Cheque
- Deposit
- Online Transfer
- Withdrawal

**Cheque** and **Online Transfer** contributed a large share of the total transaction amount.

### Transaction Status

The transaction status analysis contains:

- Completed: 434
- Failed: 26
- Pending: 19
- Reversed: 21

Out of 500 transactions, most transactions were completed successfully.

### Payment Method

The payment methods analyzed were:

- Cash
- Credit Card
- Debit Card
- Net Banking
- UPI

**Debit Card** had the highest number of transactions in the dataset.
